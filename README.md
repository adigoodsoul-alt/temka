# 💼 ТЕМЩИК — Пиксельный Roguelike (MVP)

> **Сеттинг:** Симулятор криминального "темщика" и серого схематозника.  
> **Ключевое правило:** **Деньги = ХП**. Никакой боевой системы — все конфликты, риски, облавы и сделки решаются через текстовые ивенты, диалоги и проверки характеристик. Если баланс падает до нуля — **Game Over**.

---

## 🚀 Быстрый запуск

Поскольку проект использует нативные **ES6-модули** (`import` / `export`), браузеры требуют открытия страницы через локальный веб-сервер (не через `file://`):

### Вариант 1 (Python):
```bash
# В корне проекта:
python -m http.server 3000
```
Затем откройте в браузере: `http://localhost:3000`

### Вариант 2 (Node / npx / Live Server):
```bash
npx serve .
# или через расширение Live Server в VS Code
```

## 🔄 Игровой цикл

1. **Убежище (Хаб, `HUB`):**
   - Конспиративная квартира.
   - Возможность прокачать характеристики (например, потратить кэш на новую базу дропов `+2 к Связям`).
   - Кнопка выхода на вылазку или принятие экстренного звонка.

2. **Вылазка (Локация, `EXPLORATION`):**
   - Перемещение по криминальному району.
   - Выбор точек интереса (POI): подпольный офис дропов, башня в Сити, банк на Ленинском.
   - Клик по точке интереса переключает игру в состояние диалога.

3. **Текстовые ивенты (`DIALOGUE`):**
   - Диалоговое окно с персонажем (Майор ОБЭП, Меняла из Сити, Дроповод Колян).
   - Ветвления и проверки: бросок кубика $d20 + \text{Стат} \ge \text{Сложность}$.
   - **Успех:** сочный золотисто-зеленый куш, монетный дождь, `createFx('reward')`, пополнение баланса.
   - **Провал:** облава/скам, тряска экрана (Screen Shake), красная вспышка (Hit Flash), кроваво-искровые осколки `createFx('damage')`, списание денег.
   - Если баланс $\le 0$ — автоматический переход в `GAME_OVER`.

4. **Банкротство (`GAME_OVER`):**
   - Экран с черепом и причиной краха. Кнопка перезапуска с новым стартовым балансом.

## ✨ Спецэффекты (PixelFX)

Модуль `PixelFX.js` написан по принципам SpriteFusion:
- **Pixel Snapping:** координаты частиц привязаны к целочисленной сетке без субпиксельного мыла.
- **Ограниченная палитра:** White Core $\to$ Bright Accent $\to$ Secondary $\to$ Decay.
- **Экранный сок:** `shakeScreen(intensity, duration)` и `flashScreen(color, duration)`.
- **Эффекты:** `damage` (кровавые пиксели + всплывающий красный урон), `reward`/`coins` (золотые монеты + зеленый профит), `crit` (кольцевой shockwave), `sparkle` (пиксельные 4-конечные звезды).
- Глобальная функция `createFx(type, x, y, options)` доступна как из JS-модулей, так и прямо из консоли браузера (`F12`).
